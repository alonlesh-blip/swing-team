# swing-team

מנוע המחקר של "צוות הסווינג": סורק יומי, 300 בדיקות, חמישה סטאפים ובדיקה היסטורית.
מסחר על הנייר בלבד. הקוד כאן לא שולח הוראות לשום ברוקר.

## מה רץ ומתי

- **כל יום מסחר, 22:20 UTC** (GitHub Actions): מוריד מחירים יומיים מ-Yahoo Finance לכ-530 מניות
  (S&P 500 ועוד רשימה ב-`universe/extra.csv`), מריץ את 300 הבדיקות על כל מניה, מתייג סטאפים,
  ושומר את התוצאות ב-`out/`.
- **בבוקר שאחרי** (משימה מתוזמנת ב-Claude): הצוות קורא את `out/latest.json`, בודק חדשות וכסף גדול,
  המפקפק תוקף, הבוס מחליט, ותיק הנייר והלוח מתעדכנים.

## קבצים

| קובץ | מה יש בו |
|---|---|
| `RULEBOOK.md` | ספר החוקים של הכיס |
| `config.json` | כל המספרים של החוקים: סיכון, גודל, עמלה, תנאי מעבר לכסף אמיתי |
| `engine/checks.py` | 300 הבודקים, כל אחד שורה אחת |
| `engine/setups.py` | חמשת הסטאפים כחוקים מדויקים |
| `engine/backtest.py` | הבדיקה ההיסטורית |
| `engine/paper.py` | הנהלת החשבונות של תיק הנייר |
| `engine/team_run.py` | הדבק של הריצה היומית של הצוות |
| `universe/extra.csv` | מניות נוספות ליקום. אפשר לערוך |
| `out/latest.json` | הטבלה של היום |
| `out/backtest.json` | תוצאות הבדיקה ההיסטורית |

## הרצה מקומית

    pip install -r requirements.txt
    python -m tests.test_engine          # בלי רשת
    python -m engine.run_daily           # נתוני אמת
    python -m engine.run_daily --synthetic --out /tmp/out   # נתונים מדומים

## מה הבדיקה ההיסטורית לא יודעת

היקום הוא חברי המדד של היום (הטיית שרידות), דיבידנדים לא נספרים, והביצוע מונח במחיר הפתיחה
ובמחיר הסטופ או היעד בדיוק. המספרים הם ראיה, לא הבטחה. זה לא ייעוץ השקעות.
